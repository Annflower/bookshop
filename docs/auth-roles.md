# Вход, роли и защита аналитики

В `bookshop_py` **нет отдельного входа администратора**. Авторизация единая — через обычную кнопку «Войти» (как для покупателя). Разница — в **роли пользователя** (`users.role`).

## Роли

| Роль | Значение | Доступ |
|------|----------|--------|
| `user` | обычный покупатель | каталог, корзина, избранное, жалобы, свои заказы |
| `admin` | владелец/администратор | всё, что доступно `user`, **плюс** аналитика и управление жалобами |

## Как зайти в аналитику

1. Откройте `http://localhost:8000`.
2. Нажмите **«Войти»** в правом верхнем углу (кнопка общая для всех).
3. Введите email и пароль аккаунта с ролью `admin`.
4. Нажмите **«📊 Аналитика»** в навбаре.

Для данного проекта демо-владелец:

| Email | Пароль | Роль |
|-------|--------|------|
| `owner@bookverse.ru` | `owner123456` | `admin` |

Если аккаунта-админа нет — зарегистрируйте обычного пользователя, затем задайте ему роль в БД:
```sql
UPDATE users SET role='admin' WHERE email='вы@пример.ру';
```

## Как это защищено на бэкенде

- `optional_user` — достаёт пользователя из Bearer-токена или возвращает `None` (для заказов/жалоб гостей).
- `current_user` — как `optional_user`, но требует валидный токен (иначе `401`).
- `require_admin` — `Depends(current_user)` + проверка `role == 'admin'`; иначе `403 «Доступ только для администратора»`.

Эндпоинты под `require_admin`:
- `/api/analytics/*` (order-facts, product-sales, daily-revenue, event-log, kpi, cities, reviews)
- `GET` `/api/complaints` (список)
- `PATCH` `/api/complaints/{id}` (смена статуса)

## Что НЕ требует входа

- Товары, категории, заказ (`/api/orders` — опционально), ИИ-поиск, создание жалобы, регистрация/вход — публичные.
- Избранное (`/api/favorites`) — **требует** входа (`current_user`).

## Фронтенд

- `app.js` хранит токен в `localStorage` под ключом `bv_token`.
- `apiFetch(path)` автоматически добавляет заголовок `Authorization: Bearer <token>`.
- В `analytics`-странице есть «gate»: если `currentUser.role !== 'admin'` — блок аналитики скрыт и показано сообщение «Вы не вошли как администратор».
